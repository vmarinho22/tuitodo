# i18n (en-US / pt-BR)

Data: 2026-09-18

A UI está toda em português hardcoded. O utilizador escolhe o idioma num modal Config; na primeira abertura o sistema detecta o locale do SO e cai para `en-US` se não reconhecer. Catálogo em Go, sem biblioteca extra.

## Objetivo

Mostrar a interface, erros visíveis e datas/horas no idioma escolhido (`en-US` ou `pt-BR`), com fallback `en-US`, e permitir mudar na hora sem reiniciar.

## Catálogo

Pacote `internal/i18n`. Sem JSON, sem `golang.org/x/text/message`.

- Locales: `en-US`, `pt-BR`. Constante e valor gravado usam esses códigos.
- `Catalog.T(key, args...)`: texto do locale atual; se a chave não existir nele, `en-US`; se também não, a própria chave. `args` vão para `fmt.Sprintf` no valor já escolhido.
- Chaves em inglês (`tasks.title`, `error.emptyTitle`), não o texto traduzido.
- Atalhos de teclado (`a`, `s`, `1`, `2`, …) não mudam. Só os rótulos.
- Títulos das tarefas e nomes de categoria (dados do utilizador) não se traduzem.

A `App` guarda o `Catalog`. Ao mudar o locale, reaplica títulos de painel, linha A fazer/Concluídos, Ações, atalhos de subtarefas, estados vazios e volta a formatar datas/horas da lista de Concluídos. `reload`/refresh existentes bastam depois de `SetLocale`.

Domínio e store não traduzem. Sentinelas continuam em inglês (`ErrEmptyTitle`).

## Persistência

Tabela SQLite:

```sql
CREATE TABLE IF NOT EXISTS settings (
	key TEXT PRIMARY KEY,
	value TEXT NOT NULL
);
```

Chave desta versão: `locale` (`en-US` ou `pt-BR`). `SettingsRepository` (`Get` / `Set`) no mesmo `SQLiteStore`.

Valor em falta ou inválido = “não gravado”.

## Detecção

Ordem no arranque:

1. `settings.locale` válido → usa.
2. Senão `LC_ALL`, depois `LANG`. Prefixo `pt` → `pt-BR`; `en` → `en-US`; resto ou vazio → `en-US`.
3. A detecção **não** grava. Só o Salvar do modal persiste. Sem escolha guardada, a próxima abertura volta a seguir o SO.

Sem `--lang` nesta versão.

## Config (UI)

Item na barra Ações: `s config` (rótulo traduzido: pt-BR `config`, en-US `settings`). `s` abre de qualquer painel. `c` continua categoria.

```text
┌─ Config ─────────────────────┐
│ Idioma                       │
│ English (en-US)              │
│ Português (pt-BR)            │
│                              │
│         Salvar  Cancelar     │
└──────────────────────────────┘
```

Picker no estilo do de categoria. Nomes dos idiomas **no próprio idioma**, com o código. Seleção inicial = locale atual.

Salvar grava, troca o catálogo, reaplica a UI, fecha. Cancelar / Esc não grava.

Nesta versão o modal só tem idioma. A tabela `settings` serve para mais campos depois.

## Datas e horas

O store continua a gravar `time.Time` (RFC3339). Não há parse de string de ecrã.

Cada locale declara layouts Go (referência `Mon Jan 2 15:04:05 MST 2006`) num mapa extensível. Idioma novo = nova entrada, sem `if` na UI.

| Locale | Data        | Hora      | Exemplo              |
| ------ | ----------- | --------- | -------------------- |
| en-US  | `2006-01-02` | `3:04 PM` | `2026-09-18` `8:25 AM` |
| pt-BR  | `02/01/2006` | `15:04`   | `18/09/2026` `08:25` |

`Catalog.FormatDate(t)` e `Catalog.FormatTime(t)`. Em Concluídos: data na lista esquerda e no cabeçalho do dia; hora na linha do pai.

## Erros visíveis

`catalog.Error(err)` com `errors.Is`:

- `ErrEmptyTitle`
- `ErrCategoryInUse`
- `ErrNestedSubtask`, `ErrNotAParent`, `ErrSubtaskNotFound`

Erro desconhecido → mensagem genérica traduzida. A UI não mostra `err.Error()` cru desses casos. `main` (path/open da BD, falha a correr a UI) permanece em inglês no stderr.

## Testes

- `Detect`: `pt_BR.UTF-8` → `pt-BR`; `en_US.UTF-8` → `en-US`; `fr_FR` / vazio → `en-US`; `LC_ALL` ganha a `LANG`.
- `T`: chave no locale atual; fallback para `en-US`; chave inexistente devolve a chave.
- `Error`: sentinelas conhecidas nas duas línguas; desconhecido → genérica.
- `FormatDate` / `FormatTime`: `2026-09-18` e `8:25 AM` em en-US; `18/09/2026` e `08:25` em pt-BR.
- Store: gravar/ler `locale`; inválido na BD = não gravado.

Teste de TUI do modal Config não é obrigatório.

## Fora de escopo

- Flag `--lang`.
- Mais idiomas além de en-US e pt-BR (o mapa de formatos e o catálogo devem permitir acrescentar depois).
- Traduzir títulos de tarefas ou nomes de categoria.
- Pluralização ICU / `golang.org/x/text`.
- Outros campos no modal Config.
